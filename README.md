# Flarpy Bird

A Flarpy Bird-style game made with Unity.

## Open the project

- Unity version: `6000.6.2f1`
- Open this folder in Unity Hub.
- Open `Assets/Scenes/SampleScene.unity` and press Play.

Press Space to flap. Colliding with a pipe or flying out of bounds ends the run.

The Windows build profile is in `Assets/Settings/Build Profiles/Windows.asset`.
